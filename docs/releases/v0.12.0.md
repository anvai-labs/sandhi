## What changes

| Surface | Benefit | Boundary |
|---|---|---|
| Opt-in buffered accounting | Retain admission and qualified usage through waiter cancellation; recover persisted outcomes without another model call | Unknown outcomes remain held; telemetry is not an accounting receipt |
| Linux arm64 Python wheels | Install the CPython 3.11+ stable-ABI wheel without a local Rust build | Native wheel CI covers Python 3.11–3.13; no new native proxy archive target |
| Vault handling | Report configuration errors to embedders and reject symlinked credstore entries | No automatic secret migration or provider reconfiguration |
| Dependency baseline | SentinelPass protocol 0.17.0; transport fixes; InferFlux 0.5.0 and optional AgentBrowser 1.16.0 integration evidence | AgentBrowser is a test tool, not a production dependency |
| Documentation | Visual operator guides, searchable map, light/dark/system family themes and patched documentation packages | Site follows develop; runtime release remains separate |

## Compatibility and evidence

- Buffered accounting is explicitly enabled with `SANDHI_BUFFERED_ACCOUNTING=tracked`.
  Unset or `off` retains the existing path. Read the [supported surfaces and
  failure semantics](../operator/buffered-accounting.md) before enabling it.
- The Rust MSRV is 1.95. Software versions agree across the CLI, proxy, four crates,
  Python and npm bindings; wire contract versions are independent.
- Source acceptance includes prepared admission, qualified usage, process-death
  and terminal-publication contention cases: [#336](https://github.com/anvai-labs/sandhi/pull/336),
  [#337](https://github.com/anvai-labs/sandhi/pull/337),
  [#338](https://github.com/anvai-labs/sandhi/pull/338),
  [#339](https://github.com/anvai-labs/sandhi/pull/339),
  [#340](https://github.com/anvai-labs/sandhi/pull/340).
- Existing synthetic integration suites qualified the released InferFlux 0.5.0
  origin (16 cases) and exact AgentBrowser 1.16.0 source (two dashboard/recovery
  cases with negative evidence controls). These are not actual-member results.

Follow [the release procedure](../../RELEASING.md). Preserve credentials, persisted
state, caches and rollback identities during adoption. A library upgrade does not
restart a standalone gateway; a Homebrew install does not replace a separately
managed service. Timeouts remain failures under the configured gateway deadline.
