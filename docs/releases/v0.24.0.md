# Sandhi 0.24.0: exact thinking profiles and private CA trust

Status: **source candidate**. This release carries the post-0.23 exact Qwen3.7 Plus and GLM-5.3
capability profiles and profile-scoped private CA trust for embedded provider FFI.

The Python provider constructor now accepts an optional trailing `ca_file`. Sandhi validates a
bounded regular file, parses PEM or DER once, retains the resulting certificate snapshot, and
configures replacement-only roots. Hostname and certificate verification, redirect refusal,
retry/timeout policy, and the TLS 1.2 minimum remain enforced; no process-global `SSL_CERT_FILE`
or `SSL_CERT_DIR` trust is changed.

Model admission and transport encoding use the exact Qwen and GLM catalog facts rather than
provider-name inference.
