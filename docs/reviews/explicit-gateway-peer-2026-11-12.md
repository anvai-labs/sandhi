# Explicit gateway peers, cache ownership and client usage conventions

The integrated candidate accepts an explicit gateway-facing Python/Node handle independently of its direct provider label. Chat, Messages, Responses and Gemini remain client dialects; the selected source profile, account and credential stay server-owned. A bounded server-generated convention header follows the actual emitted native or rendered output. It describes parsing semantics, without granting backend authority or turning client wire observations into source receipts.

Cache intent crosses the client hop once. The binding adds no backend-specific automatic marker or local compiled plan; the server selects the authorized target and compiles its declared cache policy. Unsupported required controls refuse before admission. Deterministic gateway HTTP/SSE failures remain terminal through the shared observer and both delivery contracts, without inference repair or fabricated final usage.

[ADR-0041](../adr/0041-explicit-gateway-peer-contract.md) defines construction, header validation, cache ownership and error handling. Strict two-hop qualification also corrects Messages block-close ordering and omits unavailable optional Chat audio/prediction counters instead of rendering invalid nulls. The qualifiers remain strict.

## Remaining acceptance

This checkpoint does not complete mandatory durable accounting/default retirement or the independent provider-identity/upstream-budget-namespace migration. Those migrations must preserve existing caps, spend, policies, original receipts and unknown holds. Native Cohere/Ollama HTTP sources also need qualification through the mandatory owner to preserve existing behavior.

Broader cache resource lifecycle, native state/account/model/endpoint/expiry fences, agent/media/subscription qualification, retained reliability occurrences and supported wheel/native platforms remain explicit gates. Synthetic source tests do not establish live cache hits, subscription entitlements, monetary savings or complete platform support.
