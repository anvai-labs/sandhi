Token semantics ↗
Fresh input
Input outside the source's reported cache-read and cache-write categories.
Cache read
Reported reused input. An absent or malformed report is not a measured zero.
Cache write
A separate reported source category. It does not prove new KV state or a retention guarantee.
Output & reasoning
Reasoning may overlap output or be separate. Add it only when the inclusion convention says it is excluded.
Illustrative protocol conversion

Source: 2 fresh + 6 read + 2 write → Gemini wire: 4 uncached + 6 read. Gemini's response format has no separate cache-write category; the server's original source split remains separate.

Cache-read share describes input composition, not currency saved. Model rates, cache writes, retention and subscription quotas determine economic benefit. Sandhi reports neutral units.

Capability matrix ↗
Client APIs
Chat, Messages, Responses and Gemini share the portable router. Native features may require a compatible backend or an explicit refusal.
Backend APIs
Qualified Chat-compatible, Messages, Responses, Gemini, Cohere and Ollama sources. Codex uses its constrained Responses profile.
Plaintext APIs
Native OpenAI-compatible Text Completions and Embeddings retain their endpoint shapes and use the same durable owner.
Subscription boundaries
GLM Coding Plan uses a Z.AI Bearer API key. It does not qualify first-party Claude Pro/Max OAuth. Codex account fencing is operator-configured, not independent identity verification.

Configured support and synthetic tests are distinct from live provider acceptance. Issuer-bound continuation ownership and broader lifecycle qualification remain separate gates.

Policy reference

Bounded defaults, explicit authority

Output default
Chat requests without a limit receive 4,096 tokens by default. Operators can override it; an explicit declared model ceiling can narrow it.
Streaming defaults
30 s setup · 90 s idle · 180 s body, under a 240 s ceiling. Configured route policy takes precedence.

These are source defaults, not a readout of this process’s effective policy. Inspect Configuration for active deadline overrides. Reservations estimate liability; they are not strict physical token guarantees. Text Completions retains its explicit native default; Embeddings reserves input only.

Standalone generation requires the original durable store and one ledger shard. Pure provider FFI remains ledger free. API-key/static Bearer credentials are distinct from managed subscription leases; client headers never grant backend credential authority.

Backends & routes

Inspect configured provider labels, endpoint protocols, credential references and immutable budget authority separately.

Routes select an authorized backend before inference. Session affinity keeps compatible turns together; a failed call is not automatically replayed elsewhere.

Budget authority is the backend record’s stored upstream_budget_scope. A family-named bucket may remain authoritative after a vendor label changes. Missing metadata is unavailable; the console never derives a namespace from the provider label.
